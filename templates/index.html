How It Works

1. Claim Decomposition: Text is split into distinct sentences, preserving abbreviations and numeric values.
2. Evidence Retrieval: Queries the local knowledge base and Wikipedia public API in parallel batches.
3. NLI Classification: Uses cross-encoder/nli-deberta-v3-small with passage selection to evaluate Entailment vs Contradiction.
4. Factual Correction: Contradicted claims optionally prompt local Ollama for corrections, which are validated against the evidence using NLI before replacement.
